# 神印 · 双境试炼

[进入游戏](https://chenfenghrf.github.io/holy-wing-trial/) · [直接打开完整游戏](https://holy-wing-trial.luz22stantonqvy.chatgpt.site/)

选择龙皓晨进入金色晨光圣殿，或选择圣采儿进入月夜城塔。

- 点击或空格跃升，E 释放技能，P 暂停，M 切换声音。
- E 技能按钮在左下角；两个人物分别记录最高分。
- 防御触发后无敌 6 秒，冷却 14 秒。
- 龙皓晨每局仅 3～4 支从天而降的飞箭，可躲避或斩断。
- 玩家可填写昵称，管理员通过专用链接查看在线玩家与游戏状态。

GitHub Pages 保留原游戏入口，并跳转到完整游戏站点。完整站点承载游戏、在线玩家服务与受保护的管理后台。

管理员 token 由服务器环境配置管理，不在仓库或公开页面中。后台页面及在线名单 API 都需要服务器验证的管理员会话。

源代码在 `app/`，开发与验证方法见 [应用说明](app/README.md)。
