# 圣采儿 · 轮回试炼

神印王座主题的同人像素飞行小游戏，可在电脑或手机浏览器中游玩，也可下载 `index.html` 后离线打开。

## 操作

| 操作 | 按键 |
| --- | --- |
| 跃升 | 点击、轻触、空格、↑ 或 W |
| 轮回之剑 | E 或画面中的技能按钮 |
| 暂停与继续 | P 或暂停按钮 |
| 切换音效 | M 或声音按钮 |

轮回之剑持续 1.65 秒，冷却 9 秒，可穿过塔楼和机关，击退附近小怪。真实之影会自动抵挡敌人或机关的撞击，随后提供 **6 秒无敌**，冷却 **14 秒**。

躲避暗影塔楼、游走魔晶、伸缩刺刃、影蝠与魔眼，挑战本地保存的最高分。无敌效果不保护坠落地面。

## 网页发布

GitHub Pages 使用 `main` 分支的根目录。更新 `index.html` 并推送后，网页会自动更新。

本项目无需安装依赖或进行构建。全部画面、样式、逻辑和音效都包含在 `index.html` 中。
