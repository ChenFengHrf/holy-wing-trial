# 神印 · 双境试炼

[进入游戏](https://chenfenghrf.github.io/holy-wing-trial/)

游戏直接运行在 GitHub Pages。选择龙皓晨进入金色晨光圣殿，或选择圣采儿进入月夜城塔。

- 点击或空格跃升，E 释放技能，P 暂停，M 切换声音。
- E 技能按钮在左下角；两个人物分别记录最高分。
- 防御触发后无敌 6 秒，冷却 14 秒。
- 龙皓晨每局仅 3～4 支从天而降的飞箭，可躲避或斩断。
- 玩家可填写昵称；在线服务可用时，每 10 秒同步一次角色、状态和分数。服务暂不可用也可继续游戏。

## 在线玩家管理

GitHub Pages 托管游戏，独立后台接收玩家报到并保护管理员名单。后台需允许外部访问才能接收普通玩家的报到；可访问服务不等于拥有管理员权限。

普通玩家使用游戏链接。只有 URL 带管理员 token 时才会跳转到后台验证，登录后清除地址栏 token。后台列表、登录会话和生产密钥由服务器保护，生产密钥不在仓库或公开页面中。

管理员可查看网络出口的国家／地区、城市（平台提供时）和脱敏 IP，按地区或入口搜索。后台标明 GitHub／站点游戏入口，并显示基于完整地址核验的共用出口；不同浏览器记录与不同真人不能等同。归属地表示网络出口的大致位置，代理或 VPN 可能影响结果；无法识别时显示“暂未识别”。完整 IP 不写入数据库，普通玩家无法读取名单和归属地。

统计按匿名浏览器访客合并标签页，显示玩家填写的昵称，不验证真实身份；90 秒未报到移出当前在线名单，不保存历史访问统计。

完整应用源代码在 `app/`，开发与验证方法见 [应用说明](app/README.md)。根目录 `index.html` 与 `app/src/game.html` 内容一致；修改后同步更新两处。
