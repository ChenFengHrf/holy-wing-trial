# 神印 · 双境试炼

[进入 GitHub 游戏](https://chenfenghrf.github.io/holy-wing-trial/)

游戏仅在 GitHub Pages 运行，选择龙皓晨进入金色晨光圣殿，或选择圣采儿进入月夜城塔。

- 点击或空格跃升，E 释放技能，P 暂停，M 切换声音。
- E 技能按钮在左下角；两个人物分别记录最高分。
- 防御触发后无敌 6 秒，冷却 14 秒。
- 龙皓晨每局仅 3～4 支从天而降的飞箭，可躲避或斩断。
- 角色、声音和最高分保存在本机浏览器。

管理员 Site 已关闭公开访问，旧后台及在线统计接口已停用。游戏已移除昵称管理、在线报到、IP 统计和管理员跳转，不连接 Site；旧的 token 链接会清除 token 并留在游戏里。

根目录 index.html 与 app/src/game.html 保持一致。开发说明见 [app/README.md](app/README.md)。
